# 涂锐 TURUI 个人网站

浅色干净风格的个人影像作品集网站。

## 文件说明

- `index.html`：主页面
- `resume.html`：简历页
- `series-speeches.html` / `series-faces.html`：系列图集
- `css/style.css`：样式
- `js/script.js`：交互
- `images/`：照片与图集
- `videos/`：本地视频
- `files/turui-resume.pdf`：简历 PDF
